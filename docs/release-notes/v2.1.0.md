## 2.1.0

2.1.0 delivers major multi-agent orchestration improvements, durable autonomous execution, Control Center,
browser lifecycle hardening, and desktop auto-healing.

### Agent System 3.0 & Control Center

- Integrated Agent System 3.0 with DAG orchestration, worker allocation, and recovery hooks.
- Control Center dashboard for live agent monitoring and browser lease telemetry.
- Infinite Loop automation with auto-rollover and decision delegation support.

### Durable Autonomous Execution

- Start, inspect, pause, resume, and stop durable desktop execution through the existing `session` tool.
- Execution and Agent browser work are separated into managed windows and bound to exact ChatGPT conversations.
- Authenticated terminal sessions can continue safely across chats without losing the process session.

### Background Browser Orchestration

- Fresh worker tabs open in the background instead of stealing focus from the active chat.
- Queued worker tabs also remain inactive when capacity later becomes available.
- Windows Chrome orchestration launches disable renderer backgrounding and background timer throttling to reduce
  background ChatGPT stalls.

### Windows Desktop & Shortcut Auto-Healing

- Desktop shortcut auto-heals on app startup and during packaging.
- Window foreground elevation reliably pops the app into view over full-screen browser windows.

### Reliability & Safety

- Worker tabs close only after durable broker lifecycle evidence says they are releasable.
- Public-history privacy verification works correctly in fork clones while still rejecting new unsafe history.
- All Computer permission state is explicit and remains confirmation-gated.

> Beta despite the version number. Behaviour may still change between releases.
