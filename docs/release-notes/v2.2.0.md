## 2.2.0

### Browser and model discovery

- Browser settings now support managed Chrome, Edge, and Brave candidates. Startup, wake, and
  window-layout helpers remain subordinate to the fork's managed-browser ownership and five-tab
  worker budget rather than opening an independent browser lifecycle.
- The companion observes the live ChatGPT model picker, including nested model/reasoning choices,
  and sends typed model state through Core to the workspace. It does not substitute a hard-coded
  catalog or silently change Goal/OpenRouter settings.

### Durable inputs and artifacts

- Text, images, and arbitrary file attachments can be staged through the main process and bound to
  the exact session/conversation. Durable input history survives restart without exposing selected
  host paths to ChatGPT.
- Image imports retain original bounded bytes separately from preview thumbnails, and attachment
  staging rejects invalid or path-swapped sources at the local trust boundary.
- `download_artifact` saves trusted native ChatGPT/OpenAI file results only when the `saveArtifact`
  capability is enabled. Destinations remain inside approved roots; downloads use bounded streaming,
  exclusive partial files, canonical-parent checks, and atomic no-overwrite publication.
- Artifact saving intentionally exposes no `device_id`. Local and remote filesystem identities stay
  separate instead of treating a path reported by another computer as a path on this computer.

### Plugins and workspace

- The completed Plugins platform is included in 2.2.0: reviewed catalog/install lifecycle, Core
  authority, bounded MCP exposure, credential handling, OAuth/service flows where supported, plugin
  workspace UI, and hash-verified license/NOTICE inventory.
- The workspace gains a collapsible/resizable sidebar, sticky timeline behavior, browser/model
  controls, and safe tool-result/file rendering while preserving the existing Control Center,
  Fleet/Devices, Core Health, coordinator, and orchestration surfaces.
- The fork keeps its canonical session token-pressure/compaction presentation and live Swarm/Control
  Center worker views. Duplicate upstream context/agent panes are not added, and the upstream
  heuristic usage-cost estimator is not presented as provider-authoritative billing data.

### Recovery and platform hardening

- Exact-conversation blocked-chat state is durable. A blocked chat's local tool calls are refused
  until it is explicitly released from the desktop session UI.
- Correctness paths that promise to search every retained session use the uncapped durable catalog,
  while ordinary UI session listing remains bounded and paged.
- OpenAI tunnel replacement is single-owner and waits for retirement of the process tree being
  replaced. Stale process output cannot mutate a later generation, and a replacement begins with no
  inherited health URL or handshake proof.
- One failed `/readyz` check is no longer enough to kill a tunnel carrying live requests; failure
  must survive a second bounded pass. Structured logs also distinguish control-plane polling errors
  from local MCP-probe failures.
- Multilingual access-limit classifications propagate into recovery decisions, recorded RTL/mixed
  answers preserve only safe direction metadata, and Linux DEB smoke cleanup can no longer replace
  the product result with a teardown-only failure.

### Architecture and verification

- 2.2.0 remains a selective port rather than an upstream merge/rebase. Persistent Core Host and
  supervisor, Agent System 3.0/Manager, Control Center, durable execution, Infinite Loop/scoped
  recovery, exact managed-browser ownership, authenticated terminal continuation, and the 2.1.4
  multi-device registry/transport with explicit `device_id` routing are preserved.
- The final upstream refresh remained at `53d5aaa`, so no newer upstream production commit appeared
  during the 2.2.0 implementation window.
- Release metadata is checked across `package.json`, `package-lock.json`, the companion manifest,
  `APP_VERSION`, this release note, the changelog, and the release artifact matrix before publishing.

> Beta despite the version number. Behaviour may still change between releases.
