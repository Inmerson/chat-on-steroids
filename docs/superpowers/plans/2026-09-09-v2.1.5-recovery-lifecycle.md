# Chat On Steroids 2.1.5 Recovery and Lifecycle Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Audit and selectively port upstream continuation, route, blocked-chat, browser/tunnel and attribution fixes without replacing fork orchestration or durable execution.

**Architecture:** Every upstream candidate is classified before editing as `ALREADY_PORTED`, `SAFE_MANUAL_PORT`, `TEST_ONLY_PORT`, `SUPERSEDED` or `REJECT`. Behavior is re-derived against fork ownership invariants; no blind cherry-pick of bridge/session/agents files.

**Tech Stack:** TypeScript, Chrome extension, HTTP bridge, durable JSON stores, Vitest.

**Spec:** `docs/superpowers/specs/2026-09-09-upstream-feature-port-v2.1.5-design.md`

## Global Constraints

- Preserve Infinite Loop, scoped recovery, manager authority, durable Execution and worker sleep/finish semantics.
- Preserve authenticated Core terminal continuation and five-tab budget.
- Each production change requires an observed RED regression first.
