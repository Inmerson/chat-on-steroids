# Chat On Steroids 2.1.5 Browser and Model Discovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port upstream browser selection/startup/wake and live ChatGPT model-picker discovery while preserving managed-window ownership and the five-tab budget.

**Architecture:** Browser preferences become non-authority user settings validated by Core. Browser launch arbitration stays in `src/main/browser.ts`; wake/startup helpers must reuse existing managed conversations rather than invent tabs. Model discovery is observational: extension/renderer reports the live ChatGPT picker state, and the app stores no fictitious model catalog.

**Tech Stack:** Electron, TypeScript, Chrome extension DOM/Fiber observers, Vitest/JSDOM.

**Spec:** `docs/superpowers/specs/2026-09-09-upstream-feature-port-v2.1.5-design.md`

## Global Constraints

- Five-tab worker budget and exact Agent/Execution conversation binding remain authoritative.
- No browser wake path may open an unbounded replacement tab.
- Preserve scoped recovery, command lease ownership and browser identity checks.
- Keep version at 2.1.4 during this subsystem.
