# Chat On Steroids 2.1.5 Final Integration and Release Preparation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate the six 2.1.5 subsystem ports, prove all protected 2.1.4 capabilities remain intact, then bump and locally package version 2.1.5 without publishing it.

**Architecture:** The exact final integration commit is the release candidate. Version/release metadata changes happen only after functional verification. Public push/tag/GitHub release and official signing remain separate explicit user-authorized actions.

**Tech Stack:** Git, npm, Vitest, Electron/Vite, electron-builder, Windows PowerShell.

**Spec:** `docs/superpowers/specs/2026-09-09-upstream-feature-port-v2.1.5-design.md`

## Global Constraints

- No wholesale upstream merge/rebase/reset.
- No deletion/replacement of Core, orchestration, Control Center, execution, worker lifecycle, updater or multi-device subsystems.
- Version target is exactly 2.1.5.
- No public push/tag/release in this plan.
