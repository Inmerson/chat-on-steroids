# Upstream 2.0.9 Coding Runtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port Code Mode, durable task plans, Codex-derived coding instructions, and automatic background command-result delivery from upstream 2.0.9 into the fork's current MCP/caller/session architecture.

**Architecture:** Keep the current Core/Plugins/Desktop/Steromi surface split and make all nested Code Mode calls re-enter the existing `dispatch()`/guard/recording path under the exact outer caller principal. Plans are durable session artifacts only; Agent System 3.0 and durable execution remain orchestration authorities. Background process results are appended only to later results from the same exact local session principal and are acknowledged transactionally.

**Tech Stack:** Electron main process, TypeScript, Zod 4, MCP server SDK, worker_threads, QuickJS WASM, Vitest.

**Spec:** `docs/superpowers/specs/2026-09-11-upstream-2.0.9-selective-port-design.md`
