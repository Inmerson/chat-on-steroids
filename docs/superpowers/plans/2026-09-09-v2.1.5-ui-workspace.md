# Chat On Steroids 2.1.5 UI and Workspace Modernization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring upstream sidebar, transcript, activity and usability improvements into the fork renderer while preserving Control Center, Fleet/Devices, Core Health and orchestration canvas.

**Architecture:** `src/renderer/main-app.ts` remains the composition root. Upstream renderer improvements are imported as small modules and initialized from that root; no upstream full-file replacement of `main.ts`, `index.html` or `styles.css` is permitted without preserving fork-owned DOM destinations and tests.

**Tech Stack:** Electron renderer, TypeScript, HTML/CSS, JSDOM/Vitest, Chrome extension content UI.

**Spec:** `docs/superpowers/specs/2026-09-09-upstream-feature-port-v2.1.5-design.md`

## Global Constraints

- Existing 2.1.4 tabs/destinations remain reachable.
- Renderer gets no Node/filesystem/network authority.
- User-provided content renders through text nodes/sanitized Markdown paths only.
- Version stays 2.1.4 during UI work.
