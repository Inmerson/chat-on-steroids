# Semantic Delta Audit: Upstream 2.0.9 Recorder & Session vs Fork 2.2.0

This audit establishes the semantic delta between upstream v2.0.9 and the current fork 2.2.0 session/recorder subsystems, classifying each candidate theme to ensure the fork's newer canonical message shards (`messages/*.json`), durable catalog, and execution state are preserved.

## Storage Safety Invariants

1. **Canonical message shards:** Fork 2.2.0 writes canonical messages to `messages/*.json` (one shard per logical message ID). Upstream v2.0.9 append-only or legacy flat message structures must NOT be reintroduced.
2. **Durable catalog:** Fork 2.2.0's `AttachmentCatalog` and `ensureAttachmentCatalog` remain authoritative for uncapped session queries.
3. **Execution state:** Fork 2.2.0 desktop execution actions (`execution_start`, `execution_status`, `execution_pause`, `execution_resume`, `execution_stop`) in `src/main/session/store.ts` remain unchanged.
