## Input test-scope ruling

Several copied upstream test files currently require a newer upstream Goal/finish/model-selection architecture that is outside this Task 1 fork-native input seam: `test/session-input.test.ts` expects `REASONING_EFFORTS`; `test/input-startup.test.ts` imports missing `src/main/session/start-input.ts`; `test/input-delivery-integration.test.ts` imports missing `src/shared/goal-templates.ts`; `test/mcp-input-images.test.ts` imports missing `src/main/session/finish.ts`; parts of `test/session-input-history.test.ts` expect `observeSessionModel` and newer finish/model semantics. These tests are **SUPERSEDED for this port as written**, not evidence that those whole upstream subsystems should be imported. Their applicable trust-boundary assertions are being replaced by fork-native focused tests (`input-routing-2.2`, `input-kernel-2.2`, `input-bridge-2.2`, `input-history-2.2`, `input-history-link-2.2`, `input-history-merge-2.2`, attachment/image tests).

This classification does not waive the grouped Task 1 combined gate. Browser/model/UI items marked **NEEDS_PORT** remain incomplete until implemented and reviewed.
