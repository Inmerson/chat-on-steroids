    Multi-computer

    Add a computer

    Install the Node Agent package on the other Windows computer, then enter a one-time pairing code. The code expires after 10 minutes and can be used once.

    Six steps, once. Custom MCP apps need ChatGPT Developer mode on the web. Full write/modify MCP is currently available to Business, Enterprise and Edu; Pro custom MCP is limited to read/fetch access.

    1. Pick a folder to share

      File tools can reach only the folders you approve. Terminal commands, if you enable Run commands, run as your OS user and are not limited to those folders. Do this first — the tunnel will not start with nothing to serve.

      None yet

    2. Create a tunnel

      Open Tunnels on the OpenAI platform and create one. Pick the same workspace you use in ChatGPT — a tunnel in another workspace will not show up later. Then copy its ID.

      Screen and mouse/keyboard control are a separate connector, so they need a second tunnel. Create another one and paste its ID here. Leave it empty to keep desktop control off in ChatGPT.

      Steromi combines Core and Desktop in one connector and needs its own Secure Tunnel on the OpenAI method. Leave this empty if you do not want to publish the all-in-one connector.

    3. Create an API key

      Create a key of type Restricted and give it only Tunnels: Read and Tunnels: Use. Leave everything else on None. Copy it once — the platform will not show it again.

    4. Start the tunnel

      Leave it running while you use the connector. It stays available when you close the window.

    5. Add it in ChatGPT

      Turn on Developer mode in ChatGPT — currently under Settings → Apps → Advanced settings, with workspace-managed plans also exposing custom apps from their Apps area. Then create one app per card below — the required one, plus the optional desktop one if you want it. Each card is a separate app in ChatGPT:

      • Use the exact name and description from the card — copy them, do not invent your own.
      • For authentication, scroll to the very bottom and pick No authentication. This app is protected by a secret address, not by a login.

    6. Add the Chrome extension

      Open chrome://extensions, turn on Developer mode, choose Load unpacked and pick the folder the button opens. It pairs with this app by itself — there is no code to type.

      Required for sub-agents: the companion extension must be loaded and connected in ChatGPT. Without it, Chat On Steroids cannot identify, open or coordinate worker chats.
